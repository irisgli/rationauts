# Code of conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1, available at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

In short: be decent to people. Assume good faith, critique the work rather than the
person, and accept that reasonable engineers disagree about design.

Report unacceptable behaviour to the maintainer via a private GitHub message. Reports
are handled confidentially.
